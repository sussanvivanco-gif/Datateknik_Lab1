## Projekt Datateknik Laboration 1
Denna webbplats presenteras ett antal bilder. Dessa bilder ska vara så enhetliga med varandra och webbplatsen

## Funktioner
- Responsiv design
- Dynamisk navigation med JavaScript
- Layout med CSS Flexbox, Grid.
- Startsida
- Presentattion av de redigerade bilderna
- Presentation om mig.
